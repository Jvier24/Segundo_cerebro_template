# Un sistema que no se usa no sirve

> [!tip] Idea en una frase
> El mejor segundo cerebro es el que vuelves a abrir mañana, no el que tiene la estructura más elegante.

Es fácil caer en la trampa de diseñar carpeta tras carpeta, crear plantillas perfectas y automatizarlo todo, para al cabo de una semana abandonar el sistema. La sofisticación se siente como progreso, pero no lo es si no cambia la forma de trabajar.

La medida de un sistema no es lo completo que está, sino **cuántas veces se usa sin fricción**.

## Resumen

- Toda regla que añade pasos tiene un coste diario.
- La rutina importa más que la arquitectura.
- Si algo estorba, se simplifica: el sistema se adapta a ti, no al revés.
